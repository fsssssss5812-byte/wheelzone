HOW TO CHANGE CAR PICTURES
==========================

Put your own photos in this folder (public/images) using these exact names:

  car-1.jpg    Honda Civic
  car-2.jpg    Honda City
  car-3.jpg    Honda BR-V
  car-4.jpg    Toyota Corolla
  car-5.jpg    Toyota Yaris
  car-6.jpg    Toyota Fortuner
  car-7.jpg    Suzuki Alto
  car-8.jpg    Suzuki Cultus
  car-9.jpg    Suzuki Swift
  car-10.jpg   BMW 3 Series
  car-11.jpg   BMW X5
  car-12.jpg   BMW 5 Series

The photo automatically replaces the drawing on every page: car cards,
detail page, brand cards, booking page, saved cars and the home banner.
If a file is missing, the drawn car is shown instead.

Tips:
- Use .jpg (lowercase). Wide photos (about 900x500 px) look best.
- Keep each file under 300 KB so the site loads fast.
- If you add the file while the site is running, refresh the page (Ctrl + F5).
- The numbers match the "id" values in src/data/cars.js.
